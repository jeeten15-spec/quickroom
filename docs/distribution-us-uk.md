# US/UK distribution: posts and public organiser emails

QuickRoom is **18+**. Do not email secondary schools or pitch K–12 pupils.
Use organisation inboxes that the event or league publishes. Send **one**
personal email, then one follow-up after five days. Do not buy lists or scrape
student addresses.

## Four short posts

### 1) University / college (Reddit, society Discord, course chat)

Need a study or group-project chat that is not another WhatsApp/GroupMe that never dies?

QuickRoom is a browser room for 18+ groups: create it, share a code, set an expiry for the assignment, no phone numbers. Not for schoolchildren.

Study setup: https://quickroom.org/study-group-chat-no-whatsapp

### 2) Hackathon organisers (Discord, Slack, LinkedIn)

If some teams still do not have Discord at kickoff, a browser room with a code is enough for the weekend: per-team chat, mentor office hours, or volunteer ops. Expires after the event. Not a secret store — keep git and keys where they belong.

Organiser page: https://quickroom.org/hackathon-chat-room

### 3) Course rep / society newsletter (150 words)

Group projects keep creating WhatsApp threads that outlive the module. For adult students, QuickRoom is a private room with a code and an end date — no app, no numbers. One person creates the room, shares the code in the existing Teams/Canvas/Discord channel, and the room expires with the deadline. Official grades stay in the VLE.

https://quickroom.org/blog/university-group-project-chat-us-uk-australia

### 4) Interview / hiring ops (LinkedIn or internal Slack)

A two-hour panel does not need a new Slack workspace. Authorised interviewers can join a private QuickRoom from the calendar invite, coordinate timing, then let it expire. Scorecards stay in the ATS.

https://quickroom.org/blog/interview-panel-chat-without-slack

## How to find more addresses without scraping students

1. Open the event’s Devpost page → “Questions? Email the hackathon manager”.
2. Open the society GitHub org → email field.
3. Open the event site footer → hello@ / team@.
4. If only a contact form exists, use the form. Do not guess `firstname.lastname@university.ac.uk`.
